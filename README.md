# Ejercicios Node.js y Express

Repositorio con ejercicios desarrollados durante el aprendizaje de Node.js y Express.

## Tecnologías utilizadas

- JavaScript
- Node.js
- Express
- JSON
- Thunder Client

## Proyectos

### 📁 Demo API
API de ejemplo para practicar la creación de servidores y endpoints con Express.

### 📁 API Personajes
API REST para gestionar personajes, incluyendo consultas, creación y filtrado dinámico.
